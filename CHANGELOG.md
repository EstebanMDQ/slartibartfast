# Changelog

## 0.1.0 - 2026-02-23

Initial release.

- Static site generation from Markdown + Jinja2 templates
- YAML front matter for per-page metadata
- Automatic navigation and XML sitemap generation
- Development server with hot reload
- Two built-in themes (default and minimal)
- Publishing control via published flag and publish_date
- CLI via `slarti` command (generate and serve subcommands)
